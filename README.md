# ÇAY DEMLEME ANAYASASI

## Resmi Bildiri

Bu depo, çayın demlenme süresini rastgele bir mutfak işi olmaktan çıkarıp **anayasal bir prosedür** haline getirmek üzere kurulmuştur.

Hiçbir bilimsel iddia taşımaz. Buna rağmen aşırı ciddiyettir.

---

## Madde 1 — Tanım

Çay, sıcak suyun yaprakla görüşmesidir. Görüşme süresi kısa olursa ihanet, uzun olursa işkence sayılır.

## Madde 2 — Yetki

Bu yazılım, çaydanlık üzerinde yargı yetkisini tek taraflı olarak üstlenir. İtiraz hakkı vardır ama dinlenmez.

## Madde 3 — Kullanım

```bash
python3 cay.py
```

Program sizden çay türünü sorar, sonra sizi yargılar, sonra bekletir, sonra yine yargılar.

## Madde 4 — Bilinen Kusurlar

- Su kaynama noktasını ölçmez.
- Çayın var olup olmadığını kontrol etmez.
- Sizi mutlu etme yükümlülüğü yoktur.

## Madde 5 — Katkı

Pull request açabilirsiniz. Kabul edilmeyecektir ama açabilirsiniz.
